# Retired — Iteration 4

Iteration 4 no longer exists as a separate iteration. The project now runs in two iterations, with more time allotted to each:

- **Iteration 2** (Spring Boot backend) picks up the backend slice of each feature below as a stretch goal.
- **Iteration 3** (Angular frontend) picks up the frontend slice of each feature below as a stretch goal, and is now the project's final iteration — it also absorbs what used to be Iteration 4's non-feature work: Docker Compose containerization, a refactor/polish pass, the updated ERD, and the final presentation.

See `ers-iteration-2-spec.md` and `ers-iteration-3-spec.md` for the current stretch goal lists. The individual feature files in this folder are unchanged and still the source of truth for requirements, technical notes, and definition of done for each feature.
