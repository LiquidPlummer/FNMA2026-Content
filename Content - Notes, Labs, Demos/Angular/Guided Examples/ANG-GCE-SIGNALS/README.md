# ANG-GCE-SIGNALS
In this project we will explore Angular's signals, which are a newer mechanism for sharing data throughout the application. We will look at writable, computed, input, output, and model signals, as well as signal effects.

If you clone this project and want to run it yourself, remember to get the node dependencies after cloning with the CLI command: `npm install`.

### Pre-requisites
 - ANG-GCE-DATABINDING - covers 1- and 2- way data binding techniques which signals will expand upon
