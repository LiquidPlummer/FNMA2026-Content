# Angular Routing Demo

Three components, three routes, one guard.

## Run

```bash
npm install
npm start
```

## Files

| File | Role |
|---|---|
| `src/app/app.routes.ts` | maps paths to components, applies the guard |
| `src/app/app.config.ts` | registers the routes with `provideRouter` |
| `src/app/app.html` | `routerLink` to navigate, `<router-outlet />` to render |
| `src/app/lock-service.ts` | holds the locked/unlocked state in a signal |
| `src/app/lock-guard.ts` | `CanActivateFn` that reads the service |
| `src/index.html` | `<base href="/">`, which the router needs |

## Demo

1. Click **Secret** while locked — you end up back on Home. The guard returned
   a `UrlTree` instead of letting the navigation through.
2. Go to **About** first, then click **Secret**. Now the redirect is visible,
   because you get bounced to a different page than the one you started on.
3. On Home, click **Toggle lock**, then click **Secret**. It opens.

The guard has no state of its own — it injects `LockService` and asks. Point
out that `inject()` works in a plain function here, no class required.
